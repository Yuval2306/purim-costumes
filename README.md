# 🎭 פורים AI — מחולל רעיונות לתחפושות

אתר אינטראקטיבי בעברית שמאפשר לבחור תחפושת לפורים, להעלות תמונה ולקבל מ־Gemini המלצות מותאמות אישית למראה, לאיפור ולאביזרים.

הפרויקט בנוי כעמוד סטטי יחיד, ללא תהליך build וללא צורך בהתקנת חבילות.

## מה האתר מציע?

- בחירה מתוך מגוון תחפושות מוכנות.
- העלאת תמונה באמצעות בחירת קובץ או גרירה ושחרור.
- תצוגה מקדימה של התמונה לפני השליחה.
- הגבלת גודל הקובץ ל־10MB.
- ניתוח התמונה וקבלת המלצות בעברית באמצעות Gemini AI.
- ממשק RTL רספונסיבי עם אנימציות ואפקטים לפורים.

## טכנולוגיות

- HTML5
- CSS3
- JavaScript ללא ספריות חיצוניות
- Google Fonts — Heebo ו־Secular One
- Gemini AI דרך Cloudflare Worker

## הרצה מקומית

אין צורך להתקין dependencies. לאחר שכפול הפרויקט, יש לפתוח טרמינל בתיקיית הפרויקט ולהריץ:

```bash
python -m http.server 8000
```

לאחר מכן פותחים בדפדפן:

```text
http://127.0.0.1:8000/purim-costumes.html
```

אפשר גם לפתוח את `purim-costumes.html` ישירות בדפדפן, אך שרת מקומי מומלץ כדי להימנע ממגבלות דפדפן על בקשות רשת.

## מבנה הפרויקט

```text
purim-costumes/
├── purim-costumes.html   # מבנה העמוד, העיצוב וכל הלוגיקה
└── README.md             # תיעוד הפרויקט
```

## איך זה עובד?

1. המשתמש בוחר תחפושת.
2. המשתמש מעלה תמונה בפורמט תמונה נתמך.
3. הדפדפן ממיר את התמונה ל־Base64.
4. התמונה, סוג הקובץ והנחיית הטקסט נשלחים ל־Cloudflare Worker.
5. ה־Worker מתקשר עם Gemini ומחזיר ניתוח והמלצות בעברית.
6. התוצאה מוצגת באתר באנימציית הקלדה.

כתובת ה־Worker מוגדרת בקבוע `WORKER_URL` בתוך הפונקציה `analyzeImage` בקובץ `purim-costumes.html`:

```js
const WORKER_URL = "https://purim-gemini.yuvalboker588.workers.dev";
```

כדי לעבוד עם Worker אחר, יש להחליף את הכתובת בערך המתאים.

## פריסה

מכיוון שזהו אתר סטטי, אפשר לפרוס אותו בשירותים כגון:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

יש לוודא שה־Cloudflare Worker מאפשר בקשות CORS מהדומיין שבו האתר נפרס.

## פרטיות ואבטחה

- התמונות נשלחות לשירות חיצוני לצורך הניתוח ואינן מעובדות רק בדפדפן.
- אין להכניס מפתח API ישירות לקוד ה־HTML או ל־JavaScript בצד הלקוח.
- מומלץ לשמור את מפתח Gemini כ־Secret ב־Cloudflare Worker.
- לפני שימוש ציבורי, מומלץ להוסיף מדיניות פרטיות, הגבלת קצב בקשות ואימות קבצים בצד השרת.

## התאמה אישית

רשימת התחפושות נמצאת במערך `COSTUMES` בקובץ ה־HTML. לכל תחפושת ניתן להגדיר:

```js
{
  emoji: "🦸",
  name: "סופרמן",
  nameEn: "Superman",
  desc: "תיאור התחפושת"
}
```

אפשר גם לשנות את הצבעים המרכזיים דרך משתני ה־CSS המוגדרים תחת `:root`.
